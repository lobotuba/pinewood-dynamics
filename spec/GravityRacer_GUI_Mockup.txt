4. ORBIT / INSPECTION BEHAVIOR
- Orbit shall be the default Design camera.
- Mouse/touch controls: orbit, zoom, pan.
- Double click/tap a component to focus.
- Home/Fit command frames the whole car.
- Preset Perspective/Top/Bottom/Front/Rear/Left/Right buttons remain visible.
- Bottom view shall make underside ballast, ground clearance, wheels, axles, and guide-rail interference easy to inspect.

Display toggles:
[ ] X-Ray
[ ] Wireframe
[ ] Wood Only
[ ] Weights Only
[ ] Wheels/Axles Only
[ ] Center of Gravity
[ ] Rules Envelope

20. KID MODE SIMPLIFICATION
Kid Mode should keep the same 3D model/physics but simplify labels and panels.
Primary controls:
- Imagine My Car
- Shape It
- Add Stuff
- Add Weight
- Wheels
- Race
- Why?
- Make It Faster
- Build It

Advanced numerical coefficients remain hidden unless opened.

21. BUILDER MODE
Builder Mode emphasizes:
- inches/ounces;
- actual materials;
- weight placement;
- dimensions;
- CG;
- wheel setup;
- legality;
- build outputs.

22. ENGINEERING LAB
Engineering Lab may expose:
- full solver state;
- physical coefficients;
- parameter provenance;
- energy residual;
- parameter sweeps;
- uncertainty/Monte Carlo controls;
- structured CSV telemetry export.

23. INTERACTION PRINCIPLES
- The car remains the visual center of the application.
- Editing is direct wherever practical: select and manipulate components in 3D.
- Numerical entry and sliders remain available for precision.
- Results are visually connected to physical causes.
- Optimization is reviewable and reversible.
- Artistic design is protected by explicit locks.
- Unknown/estimated parameters are visibly distinguished from measured values.

24. DESIGN LANGUAGE
Recommended initial visual direction:
- clean workshop/engineering aesthetic;
- dark or neutral viewport backdrop that makes wood and colored cars readable;
- high-contrast status colors for compliant/warning/fail states;
- large kid-friendly primary actions;
- detailed information in collapsible secondary panels;
- smooth transitions from Garage/Design to event-like Race mode.

25. CORE NAVIGATION SUMMARY
DESIGN -> COMPONENTS -> WHEELS -> OPTIMIZE -> RACE SETUP -> RACE -> ANALYZE -> BUILD

At every stage before Race, the complete physical car should remain inspectable in orbit view or a closely related 3D view.
