Drag a point to move it, click an edge to add a point, double-click a point to delete it. Right-click a point (or hover it and press S) to make it a smooth curve point; hover a corner and press R to round it off; drag an edge's middle handle to bend it into an arc, double-click that handle to straighten it. Alt turns off the 0.25 mm snap.
